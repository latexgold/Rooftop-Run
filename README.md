# Rooftop Run

Rooftop Run is an original offline 2.5D Android platform shooter. Sprint across city rooftops, jump gaps, dash between platforms, clear sentries with touch-friendly assisted aiming, and reach the extraction beacon. The courier and enemies are stylized, original vector-drawn characters.

## Android Studio build

1. Install Android Studio and JDK 17.
2. Clone this repository.
3. In Android Studio choose **Open**, then select the `android/` folder (not the repository root).
4. Let Gradle sync. If prompted, install Android SDK Platform 35 and Build Tools 35.
5. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**. The debug APK appears at `android/app/build/outputs/apk/debug/app-debug.apk`.
6. Install that APK on a landscape Android phone for testing.

No Godot, game engine, network permission, account, or third-party game library is required. To automate builds, add your own workflow at `.github/workflows/android.yml`; this repository intentionally does not include a workflow.

## Controls

- ◀ / ▶: move
- JUMP: jump (tap for a short hop)
- DASH: burst across a gap or dodge
- SHOOT: hold to fire; aim assist selects the nearest target ahead
- Pause: resume, mission board, or field guide

## Gameplay

12 missions span Old Town, Glass Market, and North Spire. Clear the mission's marked sentries before the exit beacon opens. Progress and unlocked missions save locally. The built-in field guide explains controls and objectives offline.

## Project

- `android/`: native Java Android Studio project
- `android/app/src/main/java/.../GameView.java`: custom Canvas rendering, platform physics, touch controls, enemies, missions, and guide

This is an initial source prototype, not a finished release. Build and test it on your device before sharing; touch layouts, physics, and performance still need real-device playtesting. The APK is generated by Android Studio or your own workflow, not committed here.
